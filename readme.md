# Convex Optimization for CPT Portfolio Selection

This project studies portfolio optimization using **Cumulative Prospect Theory
(CPT)** utility. It compares convex-optimization and gradient-based methods on
toy portfolios and a multi-asset return data set, and produces plots for
convergence, wall-clock performance, rolling backtests, and scaling behavior.

The project uses the
[`cptopt`](https://github.com/cvxgrp/cptopt) package by Eric Luxenberg,
Philipp Schiele, and Stephen Boyd. The package is installed as an external
dependency; it is no longer included in this repository.

## Project structure

## Methods

The project includes the following optimizers:

- Mean-variance frontier optimization (`MeanVarianceFrontierOptimizer`)
- Minorization-maximization (`MinorizationMaximizationOptimizer`)
- Convex-concave optimization (`ConvexConcaveOptimizer`)
- Gradient ascent (`GradientOptimizer`)
- Adam and L-BFGS baselines implemented in the experiment scripts

The default CPT parameters used by the experiments are:

```text
gamma_pos = 8.4    gamma_neg = 11.4
delta_pos = 0.77   delta_neg = 0.79
```

Create and activate a virtual environment from the project directory:

```bash
python -m venv .venv
```

On Windows:

```powershell

```

On macOS/Linux:

```bash
source .venv/bin/activate
```

Install the project dependencies and `cptopt` from its GitHub repository:

```bash
python -m pip install --upgrade pip
python -m pip install numpy pandas scipy scikit-learn matplotlib cvxpy torch tqdm
python -m pip install git+https://github.com/cvxgrp/cptopt.git
```

## Running the experiments

Run commands from the repository root so that the input data and `figures/`
directory are resolved correctly.

### Full experiment pipeline

```bash
python main.py
```

This creates the `figures/` directory if needed and writes plots such as:

- CPT utility surfaces and mean-variance frontiers
- MM, CC, and gradient convergence trajectories
- Rolling-window wealth and monthly-return comparisons
- Optimizer scaling results

### Alternate pipeline

```bash
python main1.py
```

### Wall-time comparison

```bash
python new.py
```

These scripts can take several minutes because they repeatedly solve
optimization problems over rolling windows and multiple starting points.
Results are saved as PNG files under [`figures/`](./figures).

## Using the `cptopt` package

After installing `cptopt`, the package accepts a return matrix with shape
`(observations, assets)` and returns a portfolio weight vector through the
optimizer's `weights` property:

```python
import numpy as np

from cptopt.optimizer import (
    ConvexConcaveOptimizer,
    GradientOptimizer,
    MeanVarianceFrontierOptimizer,
    MinorizationMaximizationOptimizer,
)
from cptopt.utility import CPTUtility

returns = np.random.default_rng(0).normal(0, 0.02, size=(100, 3))
initial_weights = np.full(3, 1 / 3)

utility = CPTUtility(
    gamma_pos=8.4,
    gamma_neg=11.4,
    delta_pos=0.77,
    delta_neg=0.79,
)

optimizer = GradientOptimizer(utility)
optimizer.optimize(
    returns,
    initial_weights=initial_weights,
    keep_history=True,
)

weights = optimizer.weights
print(weights)
```

The optimizer implementations also expose convergence history and wall-clock
timing where supported. Portfolio weights are expected to be nonnegative and
sum to one.

## Data

The experiment scripts read [`cpt_proxy_returns.csv`](./cpt_proxy_returns.csv).
To regenerate the proxy data, inspect and run:

```bash
python fetch_cpt_data.py
```

This step may require internet access and can depend on the availability of
the external Yahoo Finance and FRED data sources used by the script. Existing
prepared data files are sufficient for running the experiments.
